# Drink photos

One square JPG per recipe id (`<recipe id>.jpg`, 600×600). The app and the demo
site use a photo when one exists here, otherwise they draw the drink
(`static/drinkart.js`).

Sources and licenses are in `credits.json` and shown under each drink on the
drink list page:

* **TheCocktailDB** (thecocktaildb.com) — free for non-commercial use. Fine for a
  garage hobby project; replace them if this ever becomes commercial.
* **Openverse / rawpixel** — CC0 (public domain).

Entries with a `note` of "Similar drink (…)" show a different drink that looks
the same, because no photo of the exact drink was available.

Best upgrade: once the robot works, take your own photos of each drink and
drop them in here with the same file names.
